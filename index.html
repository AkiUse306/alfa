Quick start

Ready to run in minutes.

Install

# Download the release package
curl -L -o alfa.tar.gz https://github.com/AkiUse306/alfa/releases/download/1.0/alfa-1.0-linux.pkg
mkdir -p /opt/alfa && tar -xzf alfa.tar.gz -C /opt/alfa

Run

# Start the server
cd /opt/alfa/dist/server && dotnet Alfa.Server.dll

# Start the CLI
cd /opt/alfa/dist/cli && dotnet Alfa.Cli.dll --help
